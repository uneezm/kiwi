Külső webfelület
  Frontend 
   - személyes adatok, elérhetőség, visszatérő páciens e?
   - kívánt szolgáltatás, sürgősség, megjegyzés
   - megfelelő időpontok, napszakok megadása
   - dokumentumok feltöltése, egyéb megjegyzések
   - felhasználó oldali validálás, visszajelzés az elküldés sikerességéről

   Backend - API
   - validálja az adatokat,visszajelzést küld a kliens felület felé
   - ha megfelelt, akkor megfelelő formában egy ideiglenes tárolási helyre teszi, majd értesítést küld az adminisztrációs felület felé

Belső adminisztrációs felület
   Frontend

   - több fajta szűrési lehetőség az időpontok között
  
   Backend
     - időpontok tárolására tábla(k)
     -API az adatbázissal való kommunikációra
